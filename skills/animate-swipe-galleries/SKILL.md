# Swipe galleries

1. Use native horizontal scrolling and snap positions.
2. Provide explicit previous and next buttons and keep slides in reading order.
3. Use instant navigation for reduced motion and bound the available slide index.

## Apply the example

Open [example.html](examples/example.html) directly in a browser. Read [example.js](examples/example.js) for the interaction and inspect the HTML for the baseline state and CSS. Adapt the example to the existing component and event lifecycle. Remove subscriptions and cancel pending work when a framework component unmounts.

## Verify

Swipe on touch, operate buttons with keyboard, and check both endpoints.
