# Animated integration connectors

Draw the static graph first. Use a separate dash layer for pulse movement. Provide a persistent pause control and keep node relationships in HTML.

Open the [browser example](examples/example.html) and inspect the accompanying [JavaScript](examples/example.js). Use it as a starting point for the interaction, structure, and fallback states.

## Verify

Pause a signal with the keyboard and verify that node labels and connectors remain visible in reduced motion.
