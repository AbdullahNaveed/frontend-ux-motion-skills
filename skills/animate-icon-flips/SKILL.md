# Icon flips

1. Use flip motion to illustrate a real change in a pairing or status.
2. Keep semantic text outside the rotating wrapper and name the control.
3. Replace 3D rotation with an immediate state change in reduced motion.

## Apply the example

Open [example.html](examples/example.html) directly in a browser. Read [example.js](examples/example.js) for the interaction and inspect the HTML for the baseline state and CSS. Adapt the example to the existing component and event lifecycle. Remove subscriptions and cancel pending work when a framework component unmounts.

## Verify

Toggle with the keyboard and check that the label reflects the visible face.
